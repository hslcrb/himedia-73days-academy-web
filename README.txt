SI   System Integration(시스템 통합
- 내부 프로그램 자체개발을 해주는 외부전문기업
- 인사팀에서 사용할 내부인사시스템이 필요합니다.
- 계속 관리해주며 돈받는 SI도 있다
- 복잡한 기능과 업무를 사용자가 실수없이 처리할 수 있도록 정리하는 디자인
- 지금 보고있는 페이지에 어떤 버튼이, 어떤 기능이 제일 중요한가
- 요구하는 기능을 제대로 만들 수 있다.(구조적인 화면, 기능 구현, 협업프로세스가 잘 맞는다)

인하우스
- 우리 회사 서비스를 계속 키우는 곳
- 배달의민족, 당근마켓
- 자기 회사 내부에서 자기 제품, 서비스, 브랜드를 담당하는 조직/직무형태
- 우리 서비스를 만드는 회사
- 예쁘게 만드는 것이 아니라 사용자가 행동(구매)하게 만드는 것
- 기획 -> 디자인 -> 개발 -> 출시 -> 사용자 반응 확인 -> 수정 -> 다시 출시 (무한의 반복)
- 우리 서비스를 더 잘팔리고 더 많이 쓰게 만들어라(한 서비스를 오래 파면서 개선하는게 좋다)(보통 mbti N이 많다)
  
에이전시
- 트렌드에 민감해야 한다
- 고객사(인하우스, 대기업, 중견기업) 우리 회사 홈페이지 리뉴얼해주세요, 신제품 브랜드 사이트 만들어주세요
- 이 브랜드를 어떻게 보여줄것인가?
- 스크롤애니메이션, 타이포그래피, 레이아웃, 모션, 3D, 이미지스타일 트렌드파악
- 유행을 따라가기 보다 한단계 더 나가는 사람
- 고객의 목적을 현재의 시각적인 언어로 잘 표현해서 만들어라 (여러 브랜드와 다양한 디자인을 빠르게 경험하고 싶다)

마케팅 Marketing
- 그 서비스를 어떻게 알리고, 선택하고, 구매하게 만들 것인가?
- 상세페이지로 예를 들면 상품 사진을 예쁘게 배치하는 것이 아니라 관심 -> 이해 -> 신뢰 -> 욕구 -> 구매 흐름으로 설계

브랜딩 Branding

인하우스는 서비스를 개선하고, 마케팅해서 사용자를 데려오고 브랜드를 쌓아간다.
